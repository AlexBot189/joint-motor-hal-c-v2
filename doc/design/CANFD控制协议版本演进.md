# 巨蟹 CANFD 控制协议版本演进

> 项目: KWS EXOSKELETON V2  
> 总线: CAN FD, 仲裁段 1Mbps, 数据段 5Mbps (BRS)

---

## V1.0（2025-12-06）

文档: `关节模组使用协议简易说明书.pdf`

### 1. 执行器反馈报文 (0x300\|Dev_ID)

DLC=12，大端。由 SYNC(0x080)、多控报文或单轴报文触发发送。

```
[0-1]:  负载端实际位置    int16   cnt    [-32768,32767]→[-180°,180°]
[2-3]:  电机端实际速度    int16   RPM
[4-5]:  实际电流 Iq       int16   mA
[6-7]:  错误代码          uint16
[8-9]:  电机线圈温度      int16   0.1°C
[10]:   控制模式反馈      uint8   0x1=PP,0x2=PV,0x3=CSP,0x4=CSV,0x5=电流
[11]bit7: 使能状态        0=下使能,1=上使能
[11]bit6: 抱闸状态        0=吸合,1=释放
[11]bit5: 报错状态        0=正常,1=报错
[11]bit4: 到位状态        0=运行中,1=到位
[11]bit3-0: 预留
```

### 2. 单执行器控制报文 (0x100\|Dev_ID)

DLC=7，大端。

```
[0]bit7:   使能控制       0=失能,1=使能
[0]bit6:   抱闸控制       0=吸合,1=释放
[0]bit5:   清错控制       1=复位错误
[0]bit4-1: 控制模式       0x1=PP,0x2=PV,0x3=CSP,0x4=CSV,0x5=电流
[0]bit0:   预留
[1-2]:     target1        含义随模式
[3-4]:     target2        含义随模式
[5-6]:     feedforward    含义随模式
```

各模式参数含义:
| 模式 | target1 | target2 | feedforward |
|------|---------|---------|-------------|
| PP(0x1) | 目标角度 cnt | 加减速 RPM/s [0,20000] | 轮廓速度 RPM |
| PV(0x2) | 目标速度 RPM | 加减速 RPM/s | 预留 |
| CSP(0x3) | 目标角度 cnt | 预留 | 预留 |
| CSV(0x4) | 目标速度 RPM | 预留 | 预留 |
| 电流(0x5) | 目标电流 mA | 预留 | 预留 |

### 3. MIT 模式单执行器控制报文 (0x110\|Dev_ID)

DLC=9，大端。MIT 从 V1.0 就使用独立 COB-ID，不走 0x100。

```
[0]bit7:   使能
[0]bit6:   抱闸
[0]bit5:   清错
[0]bit4-1: 模式=0x6(MIT)
[1-2]:     目标位置 16bit [0-65535]
[3]+[4:7-4]: 目标速度 12bit [0-4095]
[4:3-0]+[5]: Kp 12bit [0-4095]→[0,500]
[6]+[7:7-4]: Kd 12bit [0-4095]→[0,5]
[7:3-0]+[8]: 目标力矩 12bit [0-4095]
```

### 4. 多执行器控制报文 (0x200)

DLC=64。8 个 slot × 7 字节（同单轴格式），ID 在 Byte[56-63]。

### 5. 编码器

电机端: 14bit，负载端: 16bit。单圈角度: 位置值 = (θ/360°)×65536。

### 6. 字典表

V1.0 字典表通过 SDO 操作标准 CiA402 + 厂商自定义对象。波特率映射: 1=5M,2=4M,3=2M,4=1M。

## V1.1（2026-06-30）

文档: `巨蟹CANopem字典表-V1.1.xlsx`

### 1. 执行器反馈报文变更

**DLC=12 版本小幅改动:**
- [10] 控制模式反馈枚举扩展: 新增 0x6=MIT, **0x7=力矩环**

**新增 DLC=16 版本（带力矩传感器）:**

```
[0-11]: 同 DLC=12, [10] 不再用作模式反馈
[10-11]: 力矩反馈        int16   0.05N.m  ← 新增
[12-14]: 预留            int24
[15]bit7:   使能状态
[15]bit6:   抱闸状态
[15]bit5:   报错状态
[15]bit4:   到位状态
[15]bit3-0: 控制模式反馈 0x1=PP,0x2=PV,0x3=CSP,0x4=CSV,0x5=电流,0x6=MIT,0x7=力矩环
```

### 2. 单执行器控制报文变更

mode 枚举新增: **0x6（文档有歧义，示例用 0x7）= 力矩环模式**

力矩模式参数:
- target1: 目标力矩值（文档示例 target1=0x00C8=200, 注释写 10N.m, 表头写 20N.m, 单位存疑）

代码实现: `MOTOR_MODE_TORQUE = 7`, 统一使用 7, 后续 KWS 确认后只需改一个常量。

### 3. MIT 控制报文

不变。

### 4. 新增 MIT 多执行器控制报文 (0x210)

DLC=64。6 个 slot × 9 字节（同 MIT 单轴格式），ID 在 Byte[56-61]。

### 5. 字典表新增

| 对象 | 名称 | 类型 | 单位 | 说明 |
|------|------|------|------|------|
| 0x1010 | Store parameters | RW U32 | - | Flash 保存, 任意值触发 |
| 0x6077 | 力矩传感器当前值 | RO S16 | 0.01N.m | V1.1 新增 |
| 0x2661 | 母线电流 | RO INT32 | mA | V1.1 新增 |

### 6. 字典表变更

| 对象 | V1.0 | V1.1 |
|------|------|------|
| 0x2540 波特率 | 1=5M,2=4M,3=2M,4=1M | 0=Classic 500K,1=Classic 1M,2=FD 1M/1M,3=FD 1M/2M,**4=FD 1M/5M** |
| 0x2531 零位设置 | 必须去使能 | **允许使能状态下设零位**, 新增 **sub=2 扭矩零漂标定** |
| 0x6060 运行模式 | 同上 | 新增模式 10=周期同步电流模式 |

## V1.0 vs V1.1 差异速查

| 特性 | V1.0 | V1.1 | 影响 |
|------|------|------|------|
| 0x300 DLC | 12 | 12 / 16(有力矩传感器) | 新增 torque_nm + mode_fb 字段 |
| 0x300 mode 枚举 | 0x1~0x5 | 0x1~0x7 | 新增 MIT(6) 和力矩(7) 反馈 |
| 0x100 mode 枚举 | 0x1~0x5 | 0x1~0x6(或7) | 新增力矩环控制 |
| 0x110 MIT | 有 | 不变 | - |
| 0x210 MIT多轴 | 无 | 有 | 新增 |
| 0x200 多轴 | 有 | 不变 | - |
| 0x6077 | 无 | 有 | 力矩传感器 SDO 值 |
| 0x2661 | 无 | 有 | 母线电流 SDO 值 |
| 波特率映射 | V1 | V2 | 值含义完全变化 |
| 零位设置 | 必须去使能 | 允许使能状态 | SDO 行为放宽 |

### 力矩模式值歧义处理

V1.1 文档中力矩模式在三处出现: 控制字节表头=0x6, 控制字节示例=7, 反馈字节=0x7。代码统一使用 `MOTOR_MODE_TORQUE = 7`，定义在 `motor_hal_types.h` 一处。后续 KWS 确认后只需改这一个常量，所有控制帧构造逻辑自动跟随。
