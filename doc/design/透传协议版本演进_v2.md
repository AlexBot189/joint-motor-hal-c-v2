## V1.0（2026-05-02）

文档: `外设传感器透传模块_主站使用说明.docx`

### 概述

仅有 0x680+NodeID 一帧 8 字节传感器透传帧。无模式选择，无力/力矩传感器类型选择。

### 配置字（0x5503:04）

```
bit0-15:  TxPeriodDiv250us  周期分频，0=关闭
bit16-17: BusFormat         0=Classic CAN, 1=Classic CAN, 2=CANFD no BRS, 3=CANFD BRS
bit18-31: Reserved          保留，必须为 0
```

周期基准: 1 tick = 250us
频率 = 4000 / period_div

### 周期透传帧

| 属性 | 值 |
|------|-----|
| CAN ID | 0x680 + NodeID |
| DLC | 8 |
| 格式 | 64 位小端 bit-packed |

**Payload 定义（64bit 小端）:**

| bit | 长度 | 信号 | 类型 | 说明 |
|-----|------|------|------|------|
| 0-11 | 12 | Hall_ADC0 | U12 | Hall 通道 0, 0-4095 |
| 12-23 | 12 | Hall_ADC1 | U12 | Hall 通道 1 |
| 24-35 | 12 | Hall_ADC2 | U12 | Hall 通道 2 |
| 36-49 | 14 | Force_Raw | U14 | DF181 力/力矩 CH0, 0-16383 |
| 50-61 | 12 | Knee_ADC | U12 | 膝关节 ADC |
| 62 | 1 | HW_SW_PC9 | U1 | 硬件开关, 0=低 1=高 |
| 63 | 1 | Status1 | U1 | 1=DataValid, 0=Invalid |

**解包参考代码:**
```c
uint16_t hall_adc0 = (payload >> 0)  & 0x0FFFU;
uint16_t hall_adc1 = (payload >> 12) & 0x0FFFU;
uint16_t hall_adc2 = (payload >> 24) & 0x0FFFU;
uint16_t force_raw = (payload >> 36) & 0x3FFFU;
uint16_t knee_adc  = (payload >> 50) & 0x0FFFU;
uint8_t  hw_sw_pc9 = (payload >> 62) & 0x01U;
uint8_t  data_valid = (payload >> 63) & 0x01U;
```

**代码实现:** `motor_hal.c` → `_parse_sensor_frame()`

## V1.1（2026-06-30）

文档: `KWS外部传感器透传协议修改说明.pdf`

### 变更概述

在 V1.0 基础上新增: 运行反馈帧、力传感器类型选择、发送模式选择。**V1.0 的 0x680 帧不变，向后兼容。**

### 配置字变更

```
bit0-15:  period_div         不变
bit16-17: bus_format         不变
bit18-19: mode               新增: 0=兼容, 1=运行反馈, 2=全部, 3=保留
bit20-21: force_module       新增: 0=DF181, 1=CMD_SPI
bit22-31: 保留              不变
```

SDO 写入格式不变: `23 03 55 04 PL PH CFG 00`
CFG = bus_format | (mode << 2) | (force_module << 4)

**周期基准变更: 1 tick = 0.5ms（注意: 与 V1.0 的 250us 不同）**
频率 = 2000 / period_div

### 新增模式

| mode | 名称 | 发送帧 | 发送顺序 |
|------|------|--------|---------|
| 0 | 兼容模式 | 0x680+NodeID | 仅一帧 |
| 1 | 运行反馈模式 | 0x690, 0x6A0, 0x6B0 | 690→6A0→6B0 |
| 2 | 全部模式 | 0x680, 0x690, 0x6A0, 0x6B0 | 680→690→6A0→6B0 |
| 3 | 保留 | 不发送 | - |

### 新增帧

**0x690 运行反馈帧0:** 0x690+NodeID, 8 字节
```
[0-3]: position_actual  S32 LE  cnt (与 0x6064 一致)
[4-7]: velocity_actual  S32 LE  RPM (与 0x606C 一致)
```

**0x6A0 运行反馈帧1:** 0x6A0+NodeID, 8 字节
```
[0-1]: iq_current    S16 LE  mA  (与 0x6078 一致)
[2-3]: bus_current   S16 LE  mA  (超范围时饱和)
[4-5]: motor_temp    S16 LE  0.1°C
[6-7]: error_code    U16 LE  (与 0x603F 一致)
```

**0x6B0 力/力矩反馈帧:** 0x6B0+NodeID, 8 字节

DF181 格式 (force_module=0):
```
[0-1]: force_ch0   S16 LE  CH0 14bit 符号扩展
[2-3]: force_ch1   S16 LE  CH1 14bit 符号扩展
[4]:   valid_mask  U8      bit0=CH0有效, bit1=CH1有效
[5-7]: reserved    U24     固定0
```

CMD_SPI 格式 (force_module=1):
```
[0-2]: force_raw   S24 LE  力矩原始计数
[3]:   reserved
[4]:   valid       U8      bit0=数据有效
[5]:   error       U8      错误码
[6-7]: reserved
```

### 代码新增

| 功能 | 实现 |
|------|------|
| motor_hal_sensor_config_ex() | 支持 mode + force_module 参数 |
| motor_sensor_t 扩展 | 新增 spi_force_raw_s24, spi_valid, spi_error, motor_temp_x10, iq_current, bus_current, error_code, motor_pos_raw, motor_vel_raw |
| 0x690 解析 | `_dispatch_frame()` 预处理, 存入 motor_pos_raw/motor_vel_raw |
| 0x6A0 解析 | `_dispatch_frame()` 预处理, 存入 iq_current/bus_current/motor_temp_x10/error_code |
| 0x6B0 解析 | `canopen_parse_spi_force()`, CMD_SPI S24 格式, 预处理防落入 0x680 分支 |
| 0x6B0/0x680 共存 | sensor_cache 保留 SPI 字段不被 0x680 覆盖 |

## V1.2（2026-07-22）

文档: `kws-exo_外部传感器透传协议修改说明_V1.2.pdf`

### 变更概述

在 V1.1 基础上，将 mode=3（原保留值）改为 32 字节 CAN FD 聚合透传模式。**V1.1 的 mode=0/1/2 行为不变。**

### 配置字变更

```
bit18-19: mode  3 改为 CAN FD 聚合模式（原为保留）
其余不变
```

**周期基准变更: 1 tick = 0.25ms（回到 V1.0 基准）**
频率 = 4000 / period_div

### 新增 mode=3

| 属性 | 值 |
|------|-----|
| CAN ID | 0x6C0 + NodeID |
| DLC | 32 (固定) |
| 帧格式 | CAN FD + BRS |
| 每周期帧数 | 1 帧（代替原 4 帧） |
| bus_format | 忽略，使用平台实际 CAN FD 状态 |

### 32 字节聚合帧布局

```
[0-7]:   0x680 内容 (Hall ADC×3, DF181 CH0, 膝关节 ADC, 开关, 有效位)
[8-15]:  0x690 内容 (位置 S32 LE, 速度 S32 LE)
[16-23]: 0x6A0 内容 (Iq, 母线电流, 温度, 错误码)
[24-31]: 0x6B0 内容 (CMD_SPI S24, 有效位, 错误码)
```

四段内部位定义与 V1.1 完全一致。Byte0-7 和 Byte24-31 中 CH0 来自同一次传感器读取。

### 代码新增

| 功能 | 实现 |
|------|------|
| 0x6C0 聚合帧解析 | `_dispatch_frame()` 预处理, 拆为 4 段复用现有解析, sensor_lock 保护 |
| COB_SENSOR_AGGR_BASE | 新增 `0x6C0` 常量 |
| SENSOR_MODE_AGGREGATED | 新增 `3` 常量 |
| 默认 mode | 改为 3 |

### 兼容性

- mode=0/1/2 行为完全不变
- mode=3 仅发 0x6C0 聚合帧，不同时发四帧独立帧
- period_div、force_module 切换规则不变

## V2.0 KWS CANFD V2 MIT 快控协议（2026-08-03）

文档: `KWS外骨骼CANFD_MIT快控缩放与使用指南.docx`  
固件版本: V2.00.06+  
型号: DECHANG CANFD V2 / SANXIANG CANFD V2

### 变更概述

MIT 阻抗控制从硬编码缩放改为可配置动态缩放。新增五个 SDO 对象定义 physical↔raw 换算量程。MIT 帧格式位域不变，编码公式完全重写。

### 新增 SDO 对象（0x2542~0x2546）

| OD | 含义 | 默认值 | 物理范围 | 编码方式 |
|----|------|--------|---------|---------|
| 0x2542 | 位置量程 Pmax | 314 (×0.01 = 3.14 rad) | 1~1000 | 对称量 |
| 0x2543 | 速度量程 Vmax | 314 (×0.01 = 3.14 rad/s) | 1~1000 | 对称量 |
| 0x2544 | 刚度量程 Kpmax | 50 Nm/rad | 1~50 | 非对称量 |
| 0x2545 | 阻尼量程 Kdmax | 50 Nm·s/rad | 1~50 | 非对称量 |
| 0x2546 | 力矩量程 Tmax | 20 Nm | 1~500 | 对称量 |

### MIT 编码公式（V2）

**对称量** (位置/速度/力矩, 范围 [-max, +max]):
```
raw = round((physical + max) / (2 × max) × raw_max)
```
raw_max: position=65535, velocity=4095, torque=4095

**非对称量** (Kp/Kd, 范围 [0, max]):
```
raw = round(physical / max × 4095)
```

**"零命令" raw 值:**

| 物理量 | 零值 | raw | 说明 |
|--------|------|-----|------|
| pos=0 | 0 rad | 0x8000 | 上中点 |
| vel=0 | 0 rad/s | 0x800 | 上中点 |
| Kp=0 | 0 | 0x000 | 允许 |
| Kd=0 | 0 | 0x000 | 允许 |
| torque=0 | 0 Nm | 0x800 | 上中点 |

全零 raw (8 字节全是 0x00) 为非法命令，驱动器拒绝。

### MIT 控制字变更

| 控制字 | 含义 | 说明 |
|--------|------|------|
| 0x8C | 使能 + MIT, 无抱闸 | KWS 推荐 |
| 0xCC | 使能 + 抱闸 + MIT | 兼容旧主站 |
| 0x0C | 失能, 保持 MIT | |
| 0x2C | 清故障脉冲 | 下一帧恢复 0x0C |

### 启动流程新增

```
逐节点 SDO 读取 0x2542~0x2546
  → 校验 > 0
  → 存入 motor_node_t.mit_scales
  → 编码时使用实际量程
  → 任何一次读取失败 → 使用默认值
```

### 版本迁移

旧固件 0x2546=300 Nm（V1），升级到 V2.00.06+ 后 Flash 中不会自动变更为 20 Nm。需手动执行迁移：

```
SDO 写 0x2546:00 = 20        (Tmax = 20 Nm)
SDO 写 0x2539:00 = 1         (保存 Flash)
重启 → 确认 0x2546:00 = 20   (验证)
```

### 力矩传感器零点标定协议

0x2531:00 复用操作码:

| 位域 | 含义 |
|------|------|
| bit 7:0 = 操作码 | 1=机械零位, 2=力矩标定 |
| bit 31:8 = int24 理论力矩 (mNm) | 仅 opcode=2 有效 |

打包: `packed = opcode | (torque_mNm << 8)`

范围: ±100,000 mNm (±100 Nm)

### 多轴 MIT (0x210)

| 属性 | 值 |
|------|-----|
| CAN ID | 0x210 (固定) |
| DLC | 64 |
| 槽位 | 6 槽位 × 9 字节 (ctrl + 8B payload) |
| ID 映射 | Byte56~61, 对应槽位 0~5 的 NodeID |
| 未使用槽位 | 全部填 0 |

双电机同时控制: 两槽位各填一个电机的 ctrl + MIT payload，一帧 0x210 发出。

### 代码新增

| 功能 | 文件 | 实现 |
|------|------|------|
| mit_scales_t | motor_hal_types.h | 五字段缩放结构体 |
| OD_MIT_*_SCALE | motor_hal_types.h | 新增 5 个 OD 宏 |
| 默认缩放初始化 | motor_hal.c motor_hal_add_motor | motor_node_t 新增 mit_scales 字段 |
| V2 编码公式 | motor_hal.c motor_hal_mit_control | 启动读量程 + encode_raw + 限幅四舍五入 |
| 全零检验 | motor_hal.c motor_hal_mit_control | 发送前拒绝全零 raw |
| 零值 raw | motor_hal.c motor_hal_mit_encode_raw | pos/vel/torque 零值 = 上中点 |
| 启动读量程 | main_loop.cpp poll_common | 逐节点 SDO 读 5 个 OD, 失败降级默认值 |
| 双电机 MIT | motor_hal.c motor_hal_mit_multi_ctrl_phys | 物理量 → V2 编码 → 0x210 |
| MIT 缩放迁移 | motor_hal.c motor_hal_mit_migrate_scales | 写 0x2546=20 + 0x2539=1 保存 |
| 力矩标定 | motor_hal.c motor_hal_torque_calib | opcode=2 + int24 mNm |
| 开机零漂 | motor_calib.c motor_calib_poll | 编码器零位后自动执行 τ=0 标定 |
| demo_algo MIT | demo_algo.c | mit/mit_multi/calib_torque/mit_migrate 命令 |

### Report 数据来源

config.json 新增 `report.data_source`:

| 值 | 说明 |
|----|------|
| `mixed` (默认) | 0x300 + 0x6C0 + SDO 混合, 原有逻辑 |
| `unified_6c0` | status+torque 走 0x300, 其余全走 0x6C0 (需 CAN FD rx-max-data=18) |
