# 电机控制 + 传感器评估 实战学习指南

> 原则: 边开发边实验，每轮有预期、有数据、有结论  
> 目标: 不只是协议实现者，成为懂控制、能评估、可提方案的工程师

---

## 核心实验方法

### 每轮实验标准流程

```
1. 写下预期（实验前）
   ↓
2. 跑实验，拿原始数据
   ↓
3. 数据 vs 预期，找差异
   ↓
4. 判断差异原因：协议层 / 电机层 / 环境
   ↓
5. 优化，记录
   ↓
6. 加载复测（空载通过后必须加载验证）
```

### 每次都填这张表

```
=== 实验记录 ===
日期:
实验名:
预期: （发500mA，期望力矩约0.25N.m，误差<5%）

原始数据:
电流(mA):  [100, 300, 500, 800, 1000]
力矩(N.m): [0.02, 0.07, 0.12, 0.21, 0.27]

预期 vs 实际差异:

差异原因:
  [ ] 协议层: ______
  [ ] 电机层: ______
  [ ] 环境: ______

优化/结论:

下次实验:
```

## 电机实验路线

### 第一阶段: 空载电流控制

```
目标: 验证协议正确性，拿到电机特性数据
实验: 不同电流值 → 记录电流、力矩、位置、速度反馈
关键: 每次实验前写预期，实验后对比
```

实验清单:

| # | 实验 | 命令 | 观察 |
|---|------|------|------|
| 1 | 电流阶跃 | `pdo cur 1 500` | cur 多久跟上，力矩多少 |
| 2 | Kt 标定 | cur 100/300/500/800/1000 | 电流-力矩关系，线性度 |
| 3 | 死区测量 | cur 从 0 慢慢加 | 力矩何时从 0 变正 |
| 4 | 位置保持 | cur 500 持续 10s | 位置是否漂移 |

### 第二阶段: 加载电流控制

```
目标: 空载数据和加载数据对比，暴露问题
方法: 用手推关节（模拟助力负载），观察反馈变化
```

实验清单:

| # | 实验 | 观察 |
|---|------|------|
| 5 | 加载对比 | 同样 500mA，推 vs 不推，力矩差多少 |
| 6 | 方向对称 | 正转 500mA vs 反转 500mA，力矩对称吗 |
| 7 | 低速摩擦 | cur 从 0 慢慢加，推一把看是否卡顿 |

### 第三阶段: 力矩控制

```
目标: 验证力矩环，对比电流控制
前提: 先做 tq_zero 零漂标定
```

实验清单:

| # | 实验 | 命令 | 观察 |
|---|------|------|------|
| 8 | 零漂标定 | `tq_zero 1` | 标定后空载力矩 <0.05N.m |
| 9 | 力控阶跃 | `pdo tq 1 100` | 上升时间、超调 |
| 10 | 力控正弦 | `torque_ctrl 100` | 带宽、跟踪精度 |
| 11 | 力控加载 | 推关节 | 是否能抵抗外力 |
| 12 | 力控 vs 电流 | 同样目标，两种模式对比 | 精度、响应差异 |

### 第四阶段: 其他控制模式

| # | 实验 | 命令 | 观察 |
|---|------|------|------|
| 13 | 速度控制 | `speed 100/500` | 超调、稳态误差 |
| 14 | 位置控制 | `pos 30` | 到位精度、过冲 |
| 15 | PP 轮廓 | `pp 90 500 20` | 梯形速度是否平滑 |
| 16 | MIT 阻抗 | `mit 100 10` | Kp/Kd 手感 |

## 协议层 vs 电机层判断速查

遇到异常现象时快速定位:

| 现象 | 可能协议层 | 可能电机层 |
|------|----------|----------|
| 电流反馈为 0 | 0x300 解析错 | 电流传感器坏 |
| 力矩反馈噪声大 | - | CMD_SPI 噪声或接地 |
| 命令延迟大 | mailbox 处理慢 | 电流环响应慢 |
| 力矩正弦跟不上 | SHM 频率不够 | 力矩环带宽低 |
| 位置跳变 | 编码器字节序错 | 编码器脏或磁铁偏 |
| 两台电机表现不同 | - | 机械差异或电机故障 |
| 两台电机表现相同 | 协议层问题 | - |

## 传感器评估

### 通用四问（适用任何传感器）

| 问题 | 含义 |
|------|------|
| 量程够不够？ | 被测物理量最大值在传感器范围内 |
| 精度够不够？ | 分辨率满足应用需求 |
| 响应快不快？ | ODR 和延迟满足实时性 |
| 噪声大不大？ | 静态和动态噪声在可接受范围 |

### 传感器实验清单

| # | 传感器 | 实验 |
|---|--------|------|
| S1 | IMU | 静态噪声: 放桌面 30s，看 acc/gyro 波动 |
| S2 | IMU | 翻转精度: 平放/竖放/倒放，看 roll/pitch |
| S3 | IMU | 走路波形: 手持走路录 CSV，看加速度幅值 |
| S4 | 霍尔 | 转动编码: 电机转一圈，录 hall_a/b/c 变化 |
| S5 | 霍尔 | 光滑度: 霍尔曲线有无跳变 |
| S6 | 气压计 | 静态噪声: 不动时波动 <3hPa? |
| S7 | 气压计 | 爬楼测试: 走一层楼，看气压变化 |
| S8 | CMD_SPI | 静态噪声: 空载看 spi_torque 值 |
| S9 | CMD_SPI | 标定前后: tq_zero 前后对比 |

## 每轮迭代产出清单

每做完一轮空载+加载实验，产出:

- [ ] 实验记录表（预期/数据/差异/结论）
- [ ] 一份原始数据（CSV 或截图）
- [ ] 差异分析（哪个和预期不一样，为什么）
- [ ] 问题归属（协议层/电机层/环境）
- [ ] 优化记录（改了哪里，效果）
- [ ] 下次实验计划

积累 10 轮，你有一整本工程实验手册。面试时这就不是"我写过协议"，而是"我验证过、调试过、优化过整套控制系统"。
