# 电机协议开发 + 运动控制实战学习指南

> 目的: 在做协议开发的同时，通过实验吃掉电机和传感器的知识  
> 原则: 每实现一个协议功能，就跑一个对应实验，拿到数据再往下走

## 一、电机控制：开发到哪，学到哪

### 电流控制（已完成）

**你要做什么**:

```
# 1. 发一个阶跃电流
./demo_algo pdo cur 1 500

# 2. 观察反馈
./demo_algo report | grep "M1"
```

**记录什么**:

| 记录项 | 方法 | 工具 |
|--------|------|------|
| 电流阶跃响应 | `pdo cur 1 500`，看反馈的 `m1_cur` 多久到达目标 | Web 面板或 CSV |
| 电流纹波 | 恒定 500mA，看 `m1_cur` 的波动范围 | Web 面板 |
| 电流->力矩关系 | 100/300/500/800/1000mA 各测一次，记 `m1_cur` 和 `tq_nm1` | 手动记录 |
| 温度漂移 | `torque 800` 跑 5 分钟，记 `m1_temp` vs `tq_nm1` | Web 面板 + 截图 |

**学到什么**: Kt 值、死区大小、温升影响。这三个数据算法同事一定会问。

**耗时**: 1 小时

---

### 力矩控制（刚完成）

**你要做什么**:

```
# 1. 阶跃测试
./demo_algo pdo tq 1 100    # 100×0.05=5N.m

# 2. 正弦测试  
./demo_algo torque_ctrl 100

# 3. 和电流控制对比
./demo_algo pdo cur 1 1000  # 等效电流（如果 Kt=0.05，1000mA=5N.m）
```

**记录什么**:

| 记录项 | 操作 | 对比 |
|--------|------|------|
| 力控阶跃速度 | `pdo tq 1 100`，看反馈多久到达 | 和 `pdo cur` 谁快？ |
| 力控稳态精度 | 恒定力矩命令，看力矩反馈波动 | 与电流控制对比 |
| 力控正弦跟踪 | `torque_ctrl 100`，看反馈是否能跟上正弦变化 | 频率多高开始跟丢？ |
| 力控 vs 电流在低速 | `speed 10` 慢速，分别用力控和电流控 | 哪个力矩更稳？ |

**关键实验**:

手动给关节施加不同阻力（用手推），看力控模式下电机是否自动加电流补偿。

**学到什么**: 力控带宽、力控 vs 电流控的实际差异。能回答"什么场景用力控更好"。

**耗时**: 2 小时

## 三、传感器评估：实现驱动时同步做

### IMU 评估（驱动已实现）

**你要做什么**:

```
# 1. 静态噪声
把模组放在桌面上不动，看 report 里 imu_* 字段 10 秒

# 2. 翻转测试
把模组平放→竖放→倒放，看 imu_roll/pitch 是否接近 0°/90°/180°

# 3. 敲击测试
敲桌面，看加速度有没有异常尖峰（判断 GAF 滤波效果）

# 4. 走路测试
拿着模组走路，录 CSV，画加速度波形
```

**记录什么**:

| 测试 | 期望 | 实测 | 合格? |
|------|------|------|------|
| acc 静态噪声 | <0.01g RMS | | |
| gyro 静态噪声 | <0.5dps RMS | | |
| roll 翻转误差 | <2° | | |
| GAF 融合延迟 | <10ms | | |
| 走路 acc 幅值 | 0.3-0.8g | | |

**标准参考**:

| 参数 | 差 | 可用 | 好 |
|------|----|------|-----|
| 静态噪声(acc) | >0.1g | 0.01-0.1g | <0.01g |
| 姿态精度 | >5° | 2-5° | <2° |
| 融合延迟 | >50ms | 10-50ms | <10ms |

**耗时**: 1 小时

### 霍尔传感器评估（驱动已实现，0x680 透传）

**你要做什么**:

```
# 让电机转一圈，每 10° 记录 hall_a/b/c 值
./demo_algo pos 180   # 走半圈，手动记录 hall 值
```

**记录什么**:
- 三路霍尔随角度的变化曲线（画图）
- 是否光滑？有无跳变？
- 两路之间的相位差是否 120°？

**标准**: 霍尔主要做编码器备份，精度要求不高，但变化必须光滑（无跳变说明磁铁安装 OK）。

**耗时**: 0.5 小时

---

### 气压计评估（驱动已预留）

**你要做什么**:

```
# 走楼梯：记录一楼到二楼的气压变化
# 一层楼 ≈ 30hPa，看 QMP6990 能否分辨
```

**记录什么**:
- 静态噪声（不动时的气压波动）
- 走一层楼的气压变化
- 响应速度（从一楼走到二楼，气压跟上没有）

**标准参考**: 传感器噪声应 < 3hPa（< 0.25m），否则不能分辨楼层。

**耗时**: 0.5 小时
