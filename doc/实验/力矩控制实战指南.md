## 一、电流和力矩控制的关系

电机控制有三个关键物理量，必须区分清楚：

| 符号 | 名称 | 含义 | 在你协议里 |
|------|------|------|-----------|
| **Kt** | 扭矩常数 | 电机固有属性：每安培电流产生多少力矩（N.m/A）。由磁钢强度、线圈匝数决定，出厂固定，调不了。 | `torque_nm / current_iq` 的比值 |
| **Kp** | 比例增益 | PID/阻抗控制的可调参数。决定"偏差有多大，输出反应有多强"。越大控制越猛，但也越容易震荡。 | MIT 模式: `stark_mit(kp, kd)` |
| **Kd** | 微分增益 | PID/阻抗控制的可调参数。决定"变化速度有多快，刹车有多猛"。越大阻尼越大，关节越"粘"。 | MIT 模式: `stark_mit(kp, kd)` |

### Kt vs Kp/Kd 一句话

**Kt 是电机身份证，换不了。Kp/Kd 是你手上的旋钮，随时调。**

打个比方：Kt 是车发动机的排量（1.6L 还是 2.0T，天生的），Kp 是油门踏板的灵敏度（轻踩就窜还是重踩才走，可以调），Kd 是减震器硬度（过坎颠不颠，可以调）。

## 二、电流控制调试

### 参数全解

| 参数 | 位置 | 单位 | 怎么调 |
|------|------|------|--------|
| target_Iq | `stark_torque(id, mA)` | mA | 你设定 |
| fb_current | 0x300 `current_iq` | mA | 反馈读取 |
| fb_torque | 0x300 `torque_nm` | 0.05N.m | 反馈读取 |
| 你的电机 Kt | 实验测出 | N.m/A | 下面有方法 |

### Kt 怎么测

```
./demo_algo pdo cur 1 100   → 稳定后记录 torque_nm
./demo_algo pdo cur 1 300   → 记录
./demo_algo pdo cur 1 500   → 记录
./demo_algo pdo cur 1 800   → 记录
./demo_algo pdo cur 1 1000  → 记录
```

画图：横轴电流(mA)，纵轴力矩(N.m)。直线的斜率 = Kt (N.m/A)。

每安培电流的实际力矩 = 图上斜率。比如 500mA 时力矩 0.25N.m → Kt = 0.25/0.5 = 0.5 N.m/A。

### 找到死区

从小电流慢慢加大，找到力矩刚好从零开始变正的电流值。这个值就是静摩擦等效电流。低于这个值的电流不会让关节动。

### 找到线性上限

电流加到多少力矩不再线性增长？超过这个值电机磁路饱和，多给电也是浪费。

## 三、力矩控制调试

### 参数全解

| 参数 | 位置 | 单位 |
|------|------|------|
| target_torque | `stark_torque_ctrl(id, val)` | 0.05N.m |
| fb_torque | 0x300 `torque_nm` | 0.05N.m |
| fb_current | 0x300 `current_iq` | mA（力控时驱动板自动调，你不需要管） |

### 调参流程

**1. 零漂标定**

```
./demo_algo tq_zero 1    # 电机必须去使能、空载
```

标定后空载力矩应 < 0.05N.m。如果 > 0.1N.m，再做一次。

**2. 阶跃测试**

```
./demo_algo pdo tq 1 100  # 5N.m 阶跃 (100×0.05)
```

观察 Web 面板力矩曲线：
- 上升时间：到达 90% 要多久？< 20ms 好，> 50ms 慢
- 超调量：超过目标多少？> 10% 说明力环太猛
- 稳态误差：稳定后和目标的差值

**3. 正弦跟踪**

```
./demo_algo torque_ctrl 100  # 5N.m 正弦
```

逐渐加频率：1Hz → 2Hz → 5Hz → 10Hz。找到幅值衰减到 70%（-3dB）的频率，这就是力环有效带宽。

**4. 加载测试**

用手推关节，看力矩反馈能否抵抗外力回到命令值。这是力控和电流控的核心区别——电流控对外力无反应。

## 四、电流控制 vs 力矩控制选型

| | 电流控制 | 力矩控制 |
|---|---------|---------|
| 命令 | `stark_torque(id, mA)` | `stark_torque_ctrl(id, 0.05N.m单位)` |
| 适用 | 高速摆动、快速响应 | 低速助力、变负载、承重站立 |
| 对外力反应 | 无视（只管电流） | 自动补偿（传感器闭环） |
| 带宽 | >1KHz | ~200Hz |
| 受摩擦影响 | 大 | 小（自动补偿） |

切换时注意：力矩先降到 0，加 50ms 斜坡过渡，再切模式。

## 五、写一个最简助力算法

人出 60%，机器出 40%：

```
每次循环:
    fb = stark_fb(c, 1).torque_nm × 0.05    // N.m

    if (着地):   // 力矩 > 0.5N.m 或 IMU acc_z > 1.2g
        target = fb × 0.4                     // 40% 助力
        target = clamp(target, 0, 15)         // 安全限幅
        stark_torque_ctrl(c, 1, target / 0.05)
    else:
        stark_speed(c, 1, 100)                // 摆动期速度控制
```

需要调的几个数：

| 参数 | 作用 | 起点值 | 怎么调 |
|------|------|--------|--------|
| 助力比 0.4 | 机器出力占比 | 0.4 | 0.3 弱 0.6 激进 |
| 力矩上限 | 安全保护 | 额定力矩 × 0.8 | 不超额定 |
| 斜坡时间 | 过渡平滑 | 50ms | 太短冲击 太长拖沓 |
| 着地阈值 | 判断切换 | 力矩 >0.5N.m | 看数据确定 |
