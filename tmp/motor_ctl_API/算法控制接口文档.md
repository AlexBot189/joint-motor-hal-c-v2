# Stark Motor Control API

## 文件

拷贝以下两个头文件到你的项目:

- `stark_client.h` -- 所有 API, static inline, 零依赖
- `stark_shm.h`   -- 共享内存数据结构

编译: `gcc -O2 demo_algo.c -lpthread -lrt -lm -o demo_algo`

## 快速开始

```c
#include "stark_client.h"

int main() {
    stark_client_t c;

    /* 1. 连接 SHM (允许 stark_node 后启动) */
    while (stark_open(&c) != 0) usleep(100000);

    /* 2. 等待校准完成 */
    while (!stark_ready(&c)) usleep(100000);

    /* 3. 使能 + 设电流模式 */
    stark_enable(&c, 1);  stark_enable(&c, 2);
    stark_set_mode(&c, 1, STARK_MODE_CURRENT);
    stark_set_mode(&c, 2, STARK_MODE_CURRENT);
    usleep(5000);

    /* 4. 控制循环 */
    uint32_t rt_cycle = 0;
    while (1) {
        motor_data_t m1 = stark_fb(&c, 1);
        motor_data_t m2 = stark_fb(&c, 2);
        imu_data_t   imu = stark_imu(&c);

        int32_t t1 = your_control(m1, m2, imu);
        int32_t t2 = your_control(m2, m1, imu);

        stark_multi(&c, t1, 0, 0, t2, 0, 0);
        usleep(1000);

        /* 每 200ms: 心跳 + stark_node 存活检测 */
        static int tick = 0;
        if (++tick % 200 == 0) {
            stark_heartbeat(&c);
            if (!stark_rt_alive(&c, &rt_cycle)) {
                while (!stark_ready(&c)) usleep(100000);
                stark_enable(&c, 1); stark_enable(&c, 2);
                usleep(5000);
            }
        }
    }

    stark_estop(&c, 1); stark_estop(&c, 2);
    stark_close(&c);
}
```

## API 参考

### 生命周期

```c
int  stark_open(&c)      // 连接 SHM, 返回 0 成功. 可循环重试等 stark_node 启动
void stark_close(&c)     // 断开
```

### 状态

```c
int stark_ready(&c)          // 1=校准完成
int stark_online(&c, id)     // 1=电机在线, id: 1=右 2=左
int stark_state(&c)          // 0=BOOTING 1=READY 2=RUNNING 3=FAULT
int stark_calib(&c)          // 0=空闲 1=校准中 2=完成 3=超时
int stark_severity(&c)       // 0=OK 1=WARN 2=FAULT
int stark_fault_reason(&c)   // 故障原因码
```

### 反馈 (零拷贝, 读 SHM 双 Buffer)

```c
motor_data_t  fb  = stark_fb(&c, id);     // id=1右 2左
imu_data_t    imu = stark_imu(&c);        // 9轴融合
stark_sensor_data_t s = stark_sensor(&c, id); // 传感器透传
barometer_data_t b = stark_baro(&c);      // 气压计

// motor_data_t 字段:
//   int16_t  position      编码器角度, counts [-32768,32767], [-180deg,180deg]
//                           转角度: deg = position * 360.0f / 65536.0f
//   int16_t  velocity      转速, RPM
//   int16_t  current_iq    Q轴电流, mA
//   int16_t  temperature   温度, 0.1C (除以10得摄氏度)
//   uint8_t  status_byte  状态位: bit7=使能 bit6=抱闸 bit5=错误
//   uint8_t  mode         当前控制模式
//   uint8_t  error_code   故障码

// imu_data_t 字段:
//   float  roll, pitch, yaw        欧拉角, deg
//   float  acc_x, acc_y, acc_z     加速度, g
//   float  gyro_x, gyro_y, gyro_z  角速度, dps
//   float  quat_w, quat_x, quat_y, quat_z  四元数
//   float  mag_x, mag_y, mag_z     磁力计, uT
//   float  heading_deg             航向角, deg
//   int    stationary              静止检测: 0=运动 2=静止
//   int    gyr_accuracy            陀螺精度: 0=未校准 3=精校准
```

### 控制命令 (实时, 1KHz PDO)

```c
stark_multi(c, t1,v1,p1, t2,v2,p2) // 双电机一帧 (推荐)
stark_torque(c, id, mA)           // 电流模式
stark_speed(c, id, rpm)           // CSV 速度
stark_csv(c, id, rpm)             // CSV (同 speed)
stark_position(c, id, deg)        // CSP 绝对位置, deg
stark_rel_position(c, id, delta)  // 相对位置, 自动读当前 + delta
stark_pp(c, id, deg, acc, vel)    // PP 轮廓位置
stark_pv(c, id, rpm, acc)         // PV 轮廓速度
stark_mit(c, id, pos,vel, kp,kd,tor) // MIT 阻抗
```

`stark_multi` 一发双电机, 一帧 CANFD 64B. 参数含义跟随当前控制模式:
- CURRENT 模式: 只用 t1/t2 (电流 mA), v1/v2/p1/p2 填 0
- CSP 模式: p1/p2 为绝对角度
- CSV/PV 模式: v1/v2 为速度

### 管理命令 (独立通道, 不和 mailbox 竞争)

```c
stark_enable(c, id)        // 使能
stark_disable(c, id)       // 失能 + 刹车释放 + 电流零
stark_estop(c, id)         // 急停 + 刹车抱死 + 电流零
stark_recover(c, id)       // 从急停恢复
stark_clear_fault(c, id)   // 清故障 + 自动使能 + 切电流模式
stark_set_mode(c, id, mode) // 切换控制模式
```

管理命令和控制命令不要混在同一周期发, 管理命令后至少 usleep(5000).

### 双向心跳

```c
stark_heartbeat(&c)               // 算法声明存活
int stark_rt_alive(&c, &last)     // stark_node 存活检测, 0=需重连
```

stark_node 心跳超时 (默认 1000ms) 后自动脱使能双电机, 不设 FAULT.
心跳恢复后算法自行 stark_enable 重新使能.

### 周期上报 (校准后自动开启, 5ms)

```c
const PeriodicUploadData* d = stark_report_data(&c);  // 未开启返回 NULL
uint32_t ver = stark_report_version(&c);              // 单调递增, 比对检测更新

// PeriodicUploadData 包含:
//   电机: RealtimeVelocity(RPM*10), motor_abs_angle(deg*10),
//         cal_Iq_current(mA), motor_temp(C*100), fault_code, motor_state
//   传感器: hall_a/b/c, df181_torque, knee_angle, key_landing
//   IMU: gyro_dps_x/y/z, quat_w/x/y/z, gyro_roll/pitch/yaw, acc_x/y/z
//   同步: frame_cycle, motor_ts_us, imu_ts_us, sensor_ts_us
```

## 控制模式

| 值 | 常量 | 说明 |
|:--:|------|------|
| 1 | STARK_MODE_PP | 轮廓位置, 驱动板侧梯形加减速 |
| 2 | STARK_MODE_PV | 轮廓速度, 驱动板侧梯形加减速 |
| 3 | STARK_MODE_CSP | 循环同步位置 |
| 4 | STARK_MODE_CSV | 循环同步速度 |
| 5 | STARK_MODE_CURRENT | Q轴电流直控 (外骨骼推荐) |
| 6 | STARK_MODE_MIT | MIT 阻抗控制 |

## 电机 ID

- 1: 右髋
- 2: 左髋

## 规则

1. 双电机推荐 stark_multi, 同步更好




## demo_algo 使用说明

demo_algo 是算法控制示例程序, 可参考其代码理解 API 用法.

编译: `gcc -O2 demo_algo.c -lpthread -lrt -lm -o demo_algo`

### 控制模式 (持续运行, Ctrl+C 停止)

```bash
./demo_algo torque <mA>           # 电流正弦波, 峰值=mA
./demo_algo multi  <ma1> <ma2>    # 双电机恒电流
./demo_algo speed  <rpm>          # 速度梯形波, 峰值=rpm
./demo_algo csv    <rpm>          # CSV 速度
./demo_algo pv     <rpm> [acc]    # PV 速度, acc=RPM/s
./demo_algo pos    <deg>          # 位置方波, 振幅=deg
./demo_algo csp    <deg>          # CSP 位置
./demo_algo pp     <deg> [acc] [v]# PP 位置, acc=RPM/s, v=RPM
./demo_algo mit    <kp> <kd>      # MIT 阻抗
```

示例:

```bash
./demo_algo torque 200            # 电流正弦 ±200mA
./demo_algo multi 200 200         # 双电机各 200mA
./demo_algo speed 10              # 速度 ±10RPM
./demo_algo pos 15                # 位置 ±15deg
```

### 管理命令 (执行后退出)

```bash
./demo_algo enable  1             # 使能右电机
./demo_algo disable 2             # 失能左电机
./demo_algo estop   1             # 急停右电机
./demo_algo clearf  1             # 清右电机故障
```

### 状态

```bash
./demo_algo stat                  # 只读反馈 (位置/速度/电流/IMU)
./demo_algo report                # 周期上报数据打印
```

### 注意事项

- 控制模式会自动使能+设电流模式+开始循环, 退出自动急停
- 管理命令不走控制循环, 直接执行后退出
